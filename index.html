Swagger-driven API automation framework

Give it a Swagger file. It writes runnable pytest suites that need no hardcoded IDs.

  • 0hardcoded IDs in generated tests
  • CRUDcreate, get, update and delete flows from one file
  • 3report formats: Allure, HTML and PDF

Pipeline

  1. Swagger filethe API contract
  2. Topological sortparents before dependents
  3. ID resolvermemory, suggestions, list endpoints
  4. Auth managertoken capture and refresh
  5. pytest rundependency-ordered suites
  6. Allure + LLM analysisroot-cause suggestions

What I built

  • A topological sort builds parent records before dependents, so every flow finds what it needs.
  • An ID resolver falls back from in-run memory to suggestion endpoints to list endpoints, and skips cleanly when no valid record exists.
  • Playwright captures the auth token. A manager refreshes it before expiry and injects bearer, tenant, account and workspace headers.
  • An LLM analyzer suggests root causes for failed tests.
